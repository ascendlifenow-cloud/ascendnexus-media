# ANM-WEB-121 Media Field Layout Standard

Admin media assignment fields now use the operator-first order:

1. Current assigned asset summary or preview.
2. Media Asset Picker for existing uploaded/ingested media.
3. Upload Box for new media.
4. Files selected, linked asset, warnings, and clear actions.

## Applied Areas

- Release Cover Art
- Release Full Song Audio
- Release Audio Preview
- Artist Profile Image
- Artist Thumbnail
- Artist Character Art
- Artist Banner

## Rationale

The media library is now the preferred source for already uploaded and watched-folder-ingested assets. Upload remains available, but operators should not need to re-upload an asset to assign it.

## Safety

- The fields continue using the existing media-link picker validation.
- Private and non-public-safe media URL rules are preserved.
- Full song public playback remains disabled unless explicitly configured through protected-content workflows.
