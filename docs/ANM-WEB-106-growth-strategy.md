# ANM-WEB-106 Growth Strategy

Growth analytics summarize artist count, active artist count, inactive artists, total releases, published releases, drafts, gallery count, and consent-controlled analytics event availability.

Artist roadmap data identifies each artist's release count and next recommended operational action. Artists without releases are flagged for first-release planning; artists with releases are flagged for campaign or next-release planning.

This implementation avoids personal visitor data and uses catalog state plus consent-controlled analytics counts.
