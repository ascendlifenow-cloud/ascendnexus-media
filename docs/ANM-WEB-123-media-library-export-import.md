# ANM-WEB-123 Media Library Export Import

Media Library exports include selected or complete media asset records, assignment links, storage object files where available, access classification, MIME/type metadata, file size, checksums, processing metadata present on the record, and provenance metadata.

Private and protected binaries are included only when `exportProtectedMedia` is selected by an authorized admin. Quarantined and failed/deleted storage entries are excluded from binary export by default.
