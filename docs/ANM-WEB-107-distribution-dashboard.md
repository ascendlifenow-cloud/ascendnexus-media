# ANM-WEB-107 Distribution Dashboard

The admin dashboard is available at:

- `/admin/distribution`
- `/admin/platforms`
- `/admin/distribution-history`
- `/admin/platform-health`
- `/admin/platform-analytics`
- `/admin/platform-connectors`
- `/admin/platform-rate-limits`
- `/admin/platform-errors`

It displays queued, running, completed, failed, and retry jobs; connector status; auth and rate-limit state; queue depth; analytics records; and distribution audit history.
