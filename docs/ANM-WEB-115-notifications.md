# ANM-WEB-115 Notifications

The notification center supports in-app member notifications with email, push, and digest readiness.

Notification types include:

- New artist release
- Favorite artist release
- Playlist updated
- Exclusive content
- Early access
- Membership update
- System message
- Security notification
- Platform announcement

Members can list notifications and mark individual notifications as read. Notification data is private to the current member and uses no public cache.
