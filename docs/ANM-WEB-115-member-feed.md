# ANM-WEB-115 Member Feed

The personalized feed aggregates member-owned engagement state:

- Continue listening
- Recently viewed
- Favorite count
- Following count
- Playlist count
- Unread notification count

The feed is intentionally summary-oriented and avoids embedding protected content bodies or media URLs. Recommendations continue to use ANM-WEB-114 editorial/new-release sources plus ANM-WEB-115 recommendation feedback.
