# ANM-WEB-108 Platform Comparison

## Overview

Platform comparison combines configured distribution connectors with distribution analytics to show which destinations are active, healthy, and producing measurable results.

## Inputs

Inputs include:

- Platform connector registry
- Distribution operation records
- Distribution analytics records
- Website analytics records where applicable

## Metrics

Platform summaries include:

- Connector status
- Health state
- Rate-limit state
- Upload history readiness
- Views
- Streams
- Likes
- Shares
- Comments
- Watch time
- Engagement score
- Analytics sync status

## Admin Routes

- `/admin/platform-comparison`
- `/admin/intelligence`

## Limitations

Platforms without live credentials or provider-approved APIs remain represented as connector readiness records, not fabricated performance data.
