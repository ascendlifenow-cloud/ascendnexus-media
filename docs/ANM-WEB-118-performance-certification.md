# ANM-WEB-118 Performance Certification

Performance certification checks that the performance verification commands exist and that build output succeeds.

## Evidence Commands

```bash
npm run member-portal:performance
npm run performance:baseline
npm run performance:compare
npm run build
```

Large-scale 1,000 and 10,000 user load tests require staging or production load-test infrastructure and remain launch-readiness blockers until recorded.
